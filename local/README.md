# local ディレクトリ運用ルール

このディレクトリは「ローカル専用」のスクリプトや設定ファイルを管理するためのものです。

## 目的

- データベースのマイグレーションやテスト、検証用スクリプトなど、GitHub リモートで共有・実行されるべきでないファイルを安全に管理します。
- `.gitignore`により、このディレクトリ配下のファイルは GitHub にアップロードされません。

## 例

- migration.ts : DB 構造の変更やデータ移行用スクリプト
- test-new-table.ts : 新旧テーブルのデータ比較・検証用スクリプト
- db-info.ts : DB テーブル情報取得用スクリプト
- .env : 本番用の DB 接続情報など（※絶対に GitHub に上げないこと）

## 注意事項

- このディレクトリ内のファイルは**ローカル環境でのみ実行・編集**してください。
- 機密情報や一時的な検証コードもここで管理できます。
- サンプルや雛形は`env.example`や`src/`配下で管理し、共有が必要な場合はそちらを利用してください。

---

何か運用ルールを追加したい場合は、この README を編集してください。
